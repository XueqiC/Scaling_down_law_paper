\section{Introduction}
\label{sec:intro}

LLM compression aims to reduce inference costs and memory requirements while preserving the capabilities needed for deployment. These requirements vary across applications: software engineering agents rely on code generation \citep{jimenez2024swebench,yao2023react,schick2023toolformer,liu2024agentbench}, whereas document question-answering systems require reasoning over retrieved evidence \citep{yang2018hotpotqa,ho2020constructing,trivedi2022musique}. However, the selection and configuration of compression methods, including pruning \citep{lecun1989optimal,frantar2023sparsegpt,sun2023simple}, quantization \citep{dettmers2022llmint8,frantar2022gptq,lin2023awq}, and distillation \citep{hinton2015distilling,gu2023minillm,agarwal2023gkd}, remain largely empirical because comparable resource reductions can produce substantially different capability losses. Identifying configurations that satisfy workload-specific requirements therefore often entails repeated compression and evaluation of every candidate.

Predictive compression laws seek to reduce this evaluation burden by estimating post-compression loss from model characteristics and intervention settings \citep{frantar2023scaling,kumar2024scaling,panferov2025unified,zhang2024scaling,busbridge2025distillation}. Recent laws resolve individual tasks for one method at a time \citep{sengupta2025compression,zhou2026task}, and complementary studies document heterogeneous compression effects for individual tasks and quantizers \citep{jaiswal2023compressing,liu2025quantization}. Less is known about how many measurements a capability-level prediction needs, which parts of a fitted relation carry over to another model family or compression algorithm, and when a numerical loss prediction changes the choice among compression methods. A configuration that preserves overall performance may still degrade a required capability, and existing predictions offer limited guidance on which method and level will satisfy a workload.

In this paper, we systematically investigate how compression response structure can reduce the measurements needed to develop capability scaling-down laws. Using a common framework for pruning, quantization, and distillation, we examine which aspects of the response can be shared across configurations and which depend on model state, training conditions, or evaluation distribution. We then evaluate the resulting relations through independent tests of predictive accuracy, measurement efficiency, and transfer. Finally, we assess when numerical loss prediction provides additional value for compression selection beyond simple method preferences.

Overall, our contributions are summarized below:
\begin{itemize}
\item \textbf{A systematic investigation of capability scaling-down laws.} A common framework for pruning, quantization, and distillation examines how model state, compression configuration, training data, and evaluation distribution shape capability loss and its prediction.
\item \textbf{Measurement-efficient predictive relations.} Sharing the response structure across pruning densities halves the configuration measurements needed to fit a predictor, within 0.020 nats per token of the full-grid regression on math and code, and the saving reproduces on a second model family and under a second pruning criterion: the predictive form and fitting strategy carry over, while the coefficients are estimated for each setting.
\item \textbf{Compression selection and decision analysis.} Independent selection tests separate the value of comparing methods from the additional value of numerical loss prediction: on question answering a stable method priority attains the regret of numerical selection, and configuration-level estimates add a smaller benefit on mathematics.
\end{itemize}
