# Scaling-down laws for LLM compression — paper source

LaTeX source of the ICLR 2027 submission *Developing Capability-Conditioned Scaling-Down
Laws for LLM Compression*. This repository is the one Overleaf syncs with.

- **Main document:** `main.tex` (ICLR 2027 style, nine pages of main text plus appendix).
- **Sections:** `intro.tex`, `setup.tex`, `laws.tex`, `general.tex`, `selection.tex`,
  `related.tex`, `discussion.tex`, `appendix.tex`.
- **Generated content:** `tables/*.tex` and `figs/*.pdf`. A file whose first line reads
  `% Generated by analysis/<script>.py` must not be edited by hand; change the generator
  and regenerate, otherwise the next run overwrites the edit.
- **Bibliography:** `references.bib` (every entry verified against arXiv, DBLP, or the
  publisher's proceedings; the audit lives in the companion repository).
- **Build locally:** `tectonic -X compile main.tex`.

## Companion repository

Experiment code, frozen predictions, measurements, figures' source data, the results
