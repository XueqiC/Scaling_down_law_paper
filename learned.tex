\section{Discussion and Conclusion}
\label{sec:learned}

This study set out to make the capability cost of compression predictable, and it returns three
things. The systematic investigation shows which response shapes capabilities share: mathematics
and code admit one shape under pruning with a capability-specific scale, question answering needs
its own, and the cost of reusing distillation data depends on the student and the evaluation
distribution. The predictive relations turn those observations into forms that can be fitted and
tested, and inside the controlled pruning domain a compact relation matches a regression fitted on
twice as many development configuration measurements. The selection method carries those
predictions into a decision and recovers most of the available cross-method benefit for question
answering under nominal storage constraints.

Three boundaries fix where this applies. Measurement efficiency is not stable transfer: the compact
form reaches the full-budget regression from half the measurements inside the controlled domain but
not far outside it. Configuration range, student state and evaluation distribution bound each
relation, which is why the distillation requirement is a measured interval. The selection evidence
holds for the candidate sets and storage budgets tested.
