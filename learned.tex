\section{Conclusion}
\label{sec:learned}

\rev{We present a systematic investigation of capability scaling-down laws for LLM compression. A common framework shows which parts of the response are shared, one pruning density shape across model states, families and criteria, and which are capability-specific, the intervention-dependent sensitivity of mathematics and code and the sign-changing response of question answering. Relations built on the shared structure halve the measurements a pruning predictor needs, and independent selection tests quantify when capability-level predictions change a compression choice.}
