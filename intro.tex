\section{Introduction}
\label{sec:intro}

Deployed language-model agents are specialized systems
\citep{yao2023react,schick2023toolformer,jimenez2024swebench,liu2024agentbench} whose cost scales
with each token. The model that serves such a workload is usually a reference model reduced by
pruning, quantization, or distillation, and choosing the method and its strength currently requires
measuring each candidate. Compression does not reduce capabilities uniformly: across twelve public models the same pruning
density leaves question answering the least damaged capability in some series and the most damaged in others
(Fig.~\ref{fig:heterogeneity}), and the ordering changes with model size and model family.

Existing compression laws predict an aggregate loss from sparsity, precision, training format, the
pre-pruning loss or the teacher loss
\citep{frantar2023scaling,kumar2024scaling,panferov2025unified,zhang2024scaling,busbridge2025distillation},
and studies of uneven damage document it for single tasks or single quantizers
\citep{jaiswal2023compressing,liu2025quantization,sengupta2025compression}. Three limitations
remain: the endpoint is aggregate, so a capability-specific response shape stays invisible; the
fits mix model states that differ in size and pretraining stage, so it is unclear which inputs a
relation may use when the state is new; and coefficients are rarely frozen before the test measurements.

We ask when the loss of a capability after compression can be predicted from the initial model
state and the configuration alone. The endpoint is the conditional loss on a fixed probe set
relative to a reference measured beforehand (Eq.~\ref{eq:interface}); the admitted inputs are the
initial state, meaning parameter count, pretraining tokens and reference capability losses, and
the intervention setting; no measurement of the compressed target is used. The study then proceeds in one
sequence: controlled measurements on Pythia checkpoints whose size and stage vary independently,
and on Gemma students under one distillation protocol, establish what a law must reproduce
(\S\ref{sec:observed}); an analysis of shape, conditions and mechanism explains why
(\S\ref{sec:why}); method-specific relations are built on the verified findings
(\S\ref{sec:laws}), tested with coefficients and predictions frozen in advance
(\S\ref{sec:general}), and carried into a selection rule confirmed prospectively
(\S\ref{sec:selection}). Each relation keeps the status assigned before its outcome was measured.

\paragraph{Contributions.}
\begin{itemize}
\item \textbf{A capability-conditioned standard of evidence for compression.} We replace the
aggregate loss of existing compression laws with the loss of each capability, measure pruning,
quantization and distillation under one endpoint, and admit a relation only after its coefficients
and predictions are frozen and tested on held-out states, so each relation carries the range on
which it was tested and no more. Response shapes, and not only response sizes, differ across
capabilities, and predicting a new configuration of a measured model is a different problem from
transferring to a new model state; both are properties that any such law has to respect.
\item \textbf{Predictive relations that lower the cost of measuring compression.} A relation earns
its place only if fitting it costs less than measuring the answer directly. We show that a compact
capability-conditioned relation can carry part of that cost: fitted on half of the development
configuration measurements it predicts held-out model states as accurately as a regression that
uses all of them, and the saving comes from measuring fewer settings per model rather than fewer
models, which is a design principle for any measurement panel of this kind.
\item \textbf{Compression requirements stated as measured quantities rather than assumptions.} We
replace qualitative guidance about data and protocol with quantities that can be measured and
checked: the training exposure at which reuse begins to cost more than it returns, the range of
independent data at which a capability-specific loss constraint is met, and the bound to report
when no reachable amount of data meets it. Each is stated with the range and the evaluation
distribution on which it holds.
\item \textbf{Conditions under which cross-method selection improves on a single method.} On references that
supplied no measurement to the rule, in two model families, with every candidate frozen before
measurement, the capability-specific rule recovers up to 0.89 nats of loss on question answering that
quantization alone cannot reach, and is indistinguishable from quantization elsewhere, which delimits the range in which the rule is useful as precisely as it establishes the value of
using it there.
\end{itemize}
