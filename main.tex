\begin{abstract}
LLM compression reduces inference costs and memory requirements, but selecting a method and configuration remains largely empirical because comparable resource reductions can produce different capability losses. We present a systematic investigation of capability scaling-down laws for LLM compression across pruning, quantization, and distillation. Our framework measures capability loss in mathematics, code generation, and question answering, and relates these measurements to model size, training stage, compression settings, data availability, and training exposure. We develop simple predictive relations and evaluate their accuracy, measurement efficiency, and generalization to unseen configurations and model states. The results identify response patterns that can be shared across capabilities and differences that require separate treatment. On four new model states, a compact pruning relation fitted with half the development configuration measurements achieves math and code mean absolute errors within 0.020 nats per token of a regression fitted with all measurements. Controlled distillation experiments further reveal how data reuse penalties depend on student size and evaluation distribution. Building on these findings, we formulate a compression selection method using predicted capability losses under nominal storage constraints. Independent evaluations across two model families show that the method captures most of the available cross-method benefit for question answering within the tested candidate sets, with smaller opportunities for mathematics and code. These results clarify the predictive scope of capability scaling-down laws and their use in compression method selection. Our code is publicly available at:
\url{https://anonymous.4open.science/r/scaling_down_law}.
\end{abstract}
